NEW HOME DISPLAY: each bar has 16 disjoint LED blocks, each 7 by 5 pixels with a 1px dark gap, fitting exactly into R05's original x24..155 (left) and x164..295 (right), y113..117. ACTUAL METER BALLISTICS: maximum real native level is latched between 100-RX-frame (~43ms) display updates; 2-tick (~86ms) peak visibility hold followed by 12px per tick (~300ms for a strong click to reach baseline). This shows short native transients even if a later native record is quieter when the LCD draw begins. It never creates meter peaks from the TAP beat; R05 hardware measurements already confirmed that some TAP beats have no high native peak at all. This build improves honest visibility of peaks that were reported. It does not claim to repair the earlier upstream intermittent missing-peak records.
