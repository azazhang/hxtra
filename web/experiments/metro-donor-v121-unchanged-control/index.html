This RAM session runs the original HXF MD5 93969635834cd6050dec7f137df1e4b9 without any M4/SHARC modifications, menu rebuild, or model changes. R02C metronome code is deliberately absent. The objective is to check whether the existing WebUSB RAM loader itself can run your installed donor image at startup.

Power cycling returns the unit to the previously installed v1.2.1.

Only run once after power cycling R02C. If this unchanged-donor control also freezes, R02C's new LED/SHARC code cannot explain the freeze alone: the WebUSB RAM loader, boot-memory layout or host procedure is implicated. If this control boots normally, the R02C modifications remain the primary suspects. Save the diagnostic log if either outcome occurs.
