METRO-LEDSYNC-M4LEDTRACE-R01

Read-only M4 LED timing diagnostic — not an audio-sync fix. This test runs the exact installed HXtra v1.2.1 firmware with just two M4 hook sites changed: post-filter FS3 LED sender and USB diagnostic registration. The SHARC audio program, all other non-M4 firmware entries, preset models, Global Settings, DSP Usage Display, and USB Monitor are preserved. The original donor SHA256 is 96ac133e094c75f2701226fc7cf3fca4c04b19b91aa34785e646d919979b88c0.

The M4 uses the built-in 1-microsecond timebase to store the last 16 actual LED-control ON/OFF transitions after HXtra's visibility filter. Read the data with tools/metro_ledtrace_r01_probe.py after the pedal has booted. The test does not change metronome sound or attempt synchronization.

Experimental RAM load: user-initiated only. Nine RAM regions, zero SHARC/eMMC overlay sectors, and RAM-only writes. The reference eMMC read-only CRC will be attempted if the loader can access eMMC; prior HXtra RAM tests reported status 0x10b and skipped that check. RAM transfer completion alone does not prove the firmware is running. Verify the LCD and USB editor. If the pedal freezes, power cycle to restore installed HXtra.
