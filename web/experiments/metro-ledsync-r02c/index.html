METRO-LEDSYNC-R02C-DONOR-EGRESS

R02C is the donor-preserving visible-TAP LED synchronization experiment. Its source is the exact installed HXtra v1.2.1 HXF (MD5 93969635834cd6050dec7f137df1e4b9). M4 captures the final FS3 TAP ring's OFF-to-ON command after HXtra LED color/visibility filtering, including blink-mode transitions during BPM changes. SHARC begins a click at the next audio block after this event. First visible flash after Metronome re-enable resets the accented downbeat.

Donor preservation: All 13 firmware entries beyond M4 application and SHARC loader are byte-for-byte identical to the installed HXtra v1.2.1. M4 changes are limited to five independently checked hook sites and appended diagnostic code. Original SHARC model and USB Monitor/Gain Reduction/NAM code remains intact; a single instruction in the original 142-word click kernel branches to a 15-word shim in unused PM memory. Four equivalent contiguous memory-initialization records were merged without changing final SHARC data, leaving 4 bytes under the 512 KiB partition limit. No existing HXtra feature was disabled.

Expected scope: Preset 41C, FS3 assigned TAP, Metronome Time 1/4, Accent 4. The LED must visibly flash for external phase-lock. If FS3 is not TAP or TAP visibility is turned Off, the original HXtra local metronome timing is retained. USB diagnostics command 0x50 measures LED *output commands*; actual light emission and audio acoustic alignment still require a hardware observation.

RAM only. Do not save temporary preset edits. Power cycling restores the exact installed HXtra v1.2.1. The loader checks the original installed donor sectors when available, with the pre-existing eMMC-unavailable browser exception. All application writes are redirected to RAM.
