METRO-LEDSYNC-R03A-SHARC-INPLACE-BOOTCHECK

SHARC-only, original-boot-record in-place startup check. This is the exact user's installed HXtra v1.2.1 firmware, with only one existing SHARC 142-instruction metronome PM record altered. All 201 original SHARC boot record descriptors, sizes, addresses and order are preserved. Entry2 stays 524212 bytes. The original donor M4, DSP Usage Display, USB Monitor, other DSP programs, models, presets and settings are unchanged. Donor SHA256 96ac133e094c75f2701226fc7cf3fca4c04b19b91aa34785e646d919979b88c0.

The new metronome branch is a proof-of-feasibility. This SHARC-only startup check has no M4 TAP LED event transmitter, so normal metronome behavior should remain free-running. Do not use this build to judge LED/audio synchronization. It is intended to isolate whether the new SHARC instructions can boot while preserving the donor's boot record topology. The receiver's 1-word protocol still needs integrity hardening before it becomes a final synchronization design.

Experimental RAM load, user-initiated only. Nine RAM regions. Exactly three RAM-overlay sectors: the revised SHARC CRC metadata header at eMMC sector 0x8802, one changed SHARC payload sector, and the zero-padded unchanged final partial payload sector. No permanent eMMC writes. One read-only donor-reference checksum is attempted if the loader's card is readable. The WebUSB handoff does not verify physical boot: inspect the real LCD and HX Edit editor. If the pedal freezes, save the WebUSB log and physically power cycle; do not retry a previous SHARC-failed image.
